       加载了别的 libascendcl）/或 .so 被转发 → 走下面第 5 步确诊。
  B. 有 [wcuda] 行且全部 ret=0 → 而 minimal 仍报 107002
     → 说明失败发生在 kernel 或更后面（不是 cudaMalloc），
       需看 minimal 具体在哪行报错 → 贴完整输出。
  C. 完全没有 [wcuda] 行（只有 bridge_init 三行就 cudaMalloc failed）
     → 铁证：minimal 没走这份 wcudaMalloc 实现 → 陈旧
       libcce_bridge_runtime.so 被加载 / 二进制没覆盖 → 走第 5 步。
