# 归档资料

本目录保存已经完成的计划、旧版设计、历史 code review 和参考资料。归档内容用于追溯决策，
不代表当前 `main` 的实现契约；当前能力以 `docs/02_能力清单/` 为准，当前原理以
`docs/01_架构设计/` 为准。

## 子目录

- 顶层 Markdown：历史计划、v1 设计、已完成的 review 以及从 `04_对比与验证/` 归档的过程快照
  （`CODE_REVIEW_*`、`MENTOR_REPORT_*`、`PARITY_AUDIT_*`、`RELEASE_READINESS_2026-09-02`）。
- `参考资料/asc-devkit-simt/`：Ascend SIMT 头文件和示例参考，不是转换模板。
- `参考资料/cann-runtime-kernel-exec.md`：CANN runtime/kernel 执行参考；其中部分图片和外部页面不随本仓库发布。

## 使用约定

如果归档文档与当前代码或能力矩阵冲突，以代码、自动化测试和最新真机证据为准。
